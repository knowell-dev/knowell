The Knowell panel was not built into this binary

This server was compiled without panel/dist, so it serves this placeholder page instead of the panel. The REST API under /api/v1 works as usual.

To include the panel, build it and then rebuild the server:

python scripts/buildlock.py npm --prefix panel ci
python scripts/buildlock.py npm --prefix panel run build
cargo clean -p knowell-server
python scripts/buildlock.py cargo build -p knowell

During panel development you can also point the server at a directory with PanelMode::Directory, or run npm run dev in panel/.
